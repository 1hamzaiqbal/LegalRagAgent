\subsection{Result Inclusion Policy}\label{sec:appendix:policy}

A row is used as a paper claim only when the result record names the dataset,
provider, method, answer depth, metric values, and any row note needed to
interpret the result. Rows without validated full results are omitted from the
main comparison rather than imputed.

\begin{itemize}[leftmargin=*]
\item Main benchmarks: BarExamQA and HousingQA.
\item Providers: \method{groq-llama8b}, \method{or-gemma4-26b},
\method{groq-llama70b}.
\item Main modes: \method{llm_only}, \method{rag_simple},
\method{rag_hyde}, \method{snap_hyre}, and \method{golden_passage}.
\method{rag_rewrite} is a supplemental generated-query control, and
\method{golden_plus_neighbors} is retained only as a neighbor-dilution
diagnostic.
\item Answer depth: $k=5$ for retrieval rows.
\item HousingQA interface: retrieval rows must use the jurisdiction state
filter to count as main-interface rows.
\end{itemize}

\subsection{Probe-only Exemplar Details}\label{sec:appendix:exemplar}

\input{tables/exemplar_probe_q20.tex}

The retrieval-passage exemplar probe adds one fixed, sanitized
dataset-specific real-passage-style exemplar to the generation prompt without
providing row-specific answer evidence, answer labels, or document ids. On the
20-question Gemma 4 26B retrieval slices, the exemplar improves over base
\hyre{} on the two main datasets: BarExamQA moves from Hit@5/MRR@5
0.05/0.03 to 0.15/0.09, and HousingQA moves from 0.05/0.05 to 0.10/0.10.
These are query-shape diagnostics rather than fixed-method results.
