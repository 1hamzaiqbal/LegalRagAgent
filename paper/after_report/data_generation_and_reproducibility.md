## What Generated the Final Paper Data

The result data are not generated by a single clean Python entrypoint in the
final package. The final source package contains frozen `.tex`, `.csv`, `.png`,
and `main.pdf` artifacts. The underlying JSONL evidence lives in the repository:

- Answer accuracy: `logs/**/*.jsonl`
- Retrieval exposure: `caches/retrieval/**/*.jsonl`
- Run registry: `logs/experiments.jsonl`
- Paper-facing result gate: `docs/signoff_log.md`

The historical generator is:

`paper/snap_hyre_2025_05_18/build_current_paper_assets.py`

That script can regenerate many paper assets from logs/caches, and it contains
the original Figure 3 plotting function. However, it lives in the older
working paper directory and is not safe to treat as an exact final-package
regenerator without patching, because it still carries older table/narrative
choices:

- It can emit stale exemplar table structure including Legal-Link-EU.
- It can emit stale usage/table formatting.
- It was not the exact final edit path after the audit; final source-package
  `.tex` files were manually patched after the generated asset pass.

So the honest reproducibility status is:

- JSONL-backed numbers are reproducible from logs/caches.
- Figure 3 is reproducible from the final `topk_retrieval_metrics.csv` using
  the saved script in this report.
- The final PDF is reproducible from the final LaTeX package with `tectonic`.
- The full final package is not reproducible from one single polished Python
  command without first reconciling the stale generator with the final manual
  edits.

## What I Cannot Replicate Exactly

I cannot exactly replicate `paper/icml_submission.pdf`, because:

- It was not tied to a recoverable source tree in this workspace.
- It is not byte-identical to the pre-audit zip PDF.
- Its source `.tex` package is not present as a named, canonical folder.
- Its text aligns with stale/pre-audit sections, but it appears to be compiled
  after some table updates, so it is likely a mixed artifact.

I also cannot honestly say that running
`paper/snap_hyre_2025_05_18/build_current_paper_assets.py` recreates
`paper/main.pdf` exactly. It is the historical generator, not the final
submission-package generator. The final paper is reproducible from the final
LaTeX package, and the data are traceable to JSONL, but the generator needs a
cleanup pass before it is a one-command final-package builder.

## Recommended Generator Cleanup

1. Move the final package source into a tracked canonical directory.
2. Patch `build_current_paper_assets.py` to write the final table structures:
   no Legal-Link-EU in main Table 5, five-cell token efficiency, final captions,
   final provider disclosure, and final appendix table formatting.
3. Add a `make final-paper` or `uv run ...` command that:
   - rebuilds CSVs from JSONL/cache files,
   - writes tables,
   - regenerates figures,
   - compiles `main.pdf`,
   - verifies no stale claim strings remain.
4. Add a generated manifest that records the SHA-256 of every source JSONL/cache
   used for the PDF.
