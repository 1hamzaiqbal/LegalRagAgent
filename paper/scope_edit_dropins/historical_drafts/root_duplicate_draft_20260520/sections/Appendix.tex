\section{Appendix}\label{sec:appendix}

\subsection{Source-Gated Result Policy}

The paper-facing result gate is \claimgate. A row can appear in this paper only
when that file names the detail log, the dataset, the provider, the mode, the
accuracy, and the health/caveat status. Older narrative docs, generated status
dashboards, and raw experiment summaries are supporting evidence, not the
primary citation gate.

The current exact-scored matrix is:

\begin{itemize}[leftmargin=*]
\item Benchmarks: BarExamQA, HousingQA, Legal-Link-EU, MASLegalBench.
\item Providers: \method{groq-llama8b}, \method{or-gemma4-26b},
\method{groq-llama70b}.
\item Modes: \method{llm_only}, \method{rag_simple}, \method{rag_hyde},
\method{snap_hyre}, \method{golden_passage}, \method{golden_plus_neighbors},
\method{rag_rewrite}.
\item Answer depth: $k=5$ for retrieval rows.
\item MASLegalBench exception: oracle rows are not applicable because the task
has no official per-question gold passage ids.
\end{itemize}

\subsection{Caveat Labels}

The caveat labels in Table~\ref{tab:caveats} have concrete meanings:

\begin{itemize}[leftmargin=*]
\item \textbf{COMPREHENSIVE-CLEAN}: full row signed with no promoted caveat.
\item \textbf{CITE-WITH-RETRY-CAVEAT}: same-model answer-format repair occurred
and must be mentioned when citing the row.
\item \textbf{NEAR-CAP-CAVEAT}: one or more original outputs approached the
configured completion cap, while the signed row still passed final-line and
health checks.
\item \textbf{REPAIR-CHUNK-CAVEAT}: a partial or stopped run was completed by a
same-provider/model repair chunk and merged under row-key checks.
\item \textbf{SAME-MODEL-ROUTE-CAVEAT}: the same model was reached through a
documented provider-route recovery or pinning path.
\item \textbf{SOURCE-PROXY}: retrieval exposure is a same-source-document proxy
rather than an official gold-passage metric.
\end{itemize}

These labels should remain attached to row-level claims. A plot may aggregate
caveated rows for visualization, but prose should not silently turn a caveated
row into a clean row.

\subsection{Historical Rows Not in the Main Matrix}

CaseHOLD and LegalBench-SCALR were important during earlier method development.
They are omitted from the current exact-scored main matrix because the branch
pivoted to BarExamQA, HousingQA, Legal-Link-EU, and MASLegalBench. Their logs
and older paper figures are retained for provenance. They should be described
as historical or superseded unless a new run explicitly re-adds them under the
current fixed-method \method{snap_hyre} contract and passes \claimgate.

\subsection{Tentative Exemplar Probe}

The file \method{docs/retrieval\_passage\_exemplar\_probe\_2026-05-20.md}
describes a probe-only \method{snap_hyre_exemplar} variant. It adds one
dataset-specific real passage-style exemplar to the generation prompt without
providing row-specific answer evidence. The q20 retrieval probe improved over
canonical \hyre{} on all four slices, but it is not part of the main matrix and
should not be promoted until downstream answer checks, qrel audits, and signoff
rows exist.
