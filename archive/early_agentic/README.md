# Early agentic course-project archive

This directory preserves the untracked February-March 2026 agentic legal-RAG
course-project materials that were removed from the active repository surface
during the 2026-07-17 cleanup.

These files predate the SCOPE/Snap-HyRE work and the later three-dial and OPD
directions. They are historical inputs, not validated current results. In
particular, the screenshots and reports should not be cited as active benchmark
evidence without re-running the underlying experiments.

The files were imported byte-for-byte from
`01_early-agentic-course-project_2026-02_to_2026-03.zip`. Their source hashes
are recorded in the cleanup archive's
`01_early-agentic-course-project_2026-02_to_2026-03.contents.sha256` manifest.

Restore or inspect this snapshot by checking out branch
`codex/archive/early_agentic_20260717`. Do not merge this directory back into
an active research branch wholesale; copy only material that has been reviewed
and is still relevant.
