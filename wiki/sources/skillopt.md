# SkillOpt

## TL;DR

SkillOpt treats a skill document as external trainable state. A separate model
proposes bounded text edits, and validation gates accept only improvements.

## Bearing

SkillOpt is both a close baseline and a useful methodological model: bounded
updates, rejected-edit history, and held-out gates reduce false progress. It
optimizes external text, not resource-response preservation in weights.
