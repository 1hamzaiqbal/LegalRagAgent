# BAVT

## TL;DR

BAVT is a training-free agent search method whose node selection changes with
the remaining resource ratio and whose residual value predictor prunes
unproductive steps/tool calls.

## Bearing

Generic budget-aware pruning and inference-time resource adaptation are
occupied. Use BAVT as an inference-time control baseline if the project expands
beyond one tool; it does not address cross-scale conditional-policy transfer.
