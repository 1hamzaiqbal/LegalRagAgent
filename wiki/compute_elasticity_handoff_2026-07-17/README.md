# Compute-elasticity handoff

## Decision

Do **not** start by implementing “Skill0 + Thinking Machines + OPD” as a new
method. Every broad component is already occupied by close 2025–2026 work.
Start with a sharper empirical question:

> **Can a smaller agent preserve a stronger teacher's counterfactual policy
> over changing resource prices, including prices never used in training, or
> does distillation collapse a conditional metapolicy into one average
> always-tool or never-tool strategy?**

This is domain-general. Legal retrieval is a later stress test, not the first
benchmark. The first environment should contain one priced Python action, one
fixed hard token cap, procedurally generated verifiable tasks, and separately
logged reward components.

No new training method is justified yet. The first result should establish
whether the phenomenon exists and whether simple conditional SFT or direct RL
already solves it. A method contribution is warranted only if those baselines
fail in a reproducible way.

## First go/no-go experiment

Before training anything, run one capable teacher on the same held-out tasks
at a price grid. Continue only if all are true:

1. tool-use probability changes materially with price;
2. the change is task- and difficulty-dependent, not a global switch;
3. the teacher's success/cost frontier beats always-tool and never-tool;
4. the optional teacher-only skill improves held-out utility or calibration;
5. results are not explained by prompt noncompliance or reward formatting.

If this gate fails, stop. There is no elasticity to distill.

## Relationship to the old tracks

The old three-dial work remains useful evidence that retrieval exposure,
reader conversion, and cost can move independently. It does not force this
project to remain legal or retrieval-only. This handoff isolates the most
general downstream question: whether an agent can learn a controllable policy
over resource use and whether that policy transfers across model scale.
