## Verification rules

- PDF custody is verified with `sha256sum -c` on EIT.
- Repository custody is verified by comparing every manifest commit with
  `git rev-parse HEAD`.
- Dataset files are checksummed separately from papers.
- A downloaded paper is not marked “read” merely because it is archived; the
  literature matrix distinguishes decisive full reads from discovery custody.
- Repository working trees in the vault are immutable references. Experiment
  adaptations belong in the project implementation tree, not inside them.
